# Shabnam

https://github.com/rastikerdar/shabnam-font

Shabnam by Saber Rastikerdar is distributed under the SIL Open Font License 1.1.
See OFL.txt for the full upstream copyright and license notice.

The font is bundled locally for the extension popup. No remote font requests
are made and the font is not injected into host websites.
